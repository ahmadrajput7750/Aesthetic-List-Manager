# Aesthetic-List-Manager
List Manager is a simple web app built with HTML, CSS, and JavaScript that helps users organize tasks efficiently. It allows adding, deleting, and managing list items with a clean and responsive interface while practicing DOM manipulation, event handling, and frontend development skills.

The main goal of this project is to practice frontend development concepts while creating a practical productivity tool that can be used in real life.

Features:
  Add new list items
  Delete unwanted items
  Mark tasks as completed
  Responsive and clean UI
  Real-time interaction using JavaScript
Technologies Used:
  HTML
  CSS
  JavaScript
